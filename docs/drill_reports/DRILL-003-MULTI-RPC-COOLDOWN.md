## 1. 演练场景描述

模拟 Pay3 服务实例接入多个 RPC 节点（例如主节点 A、备节点 B、备节点 C）。
测试在以下异常注入下的系统自愈表现：
1. 请求通过原子计数器 `round_robin_counter` 在 A、B 之间均匀轮询分发。
2. 节点 A 突然被限频（返回 HTTP 429 Too Many Requests）或发生网络超时。
3. 系统自动触发阶梯 CD 冷却隔离（初次 5s），后续流量 100% 自动路由到健康节点 B。
4. CD 到期后，系统自动半开探测 A，成功后自动恢复均匀分发；若持续失败则 CD 逐步升级至 10s、60s。
